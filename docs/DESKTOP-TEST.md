# Windows 桌面测试记录 — 2026-10-28

使用 Computer Use 操作实际后台助手窗口。通过本机 Launch.ps1 在普通桌面启动，使用真实 Ctrl+C / Ctrl+V 与 Windows 系统剪贴板。全程为离线模拟，模型名与密钥为空，没有调用真实 LLM，也没有游戏客户端。

| 操作 | 观察到的结果 | 状态 |
|---|---|---|
| 启动器启动 | 展示最新讽刺人格说明，默认离线监听，试用面板完整可见 | 通过 |
| 准备玛拉顿 LFM → Ctrl+C | 状态显示离线模拟、发挥、51 字节；最近返回显示 `TREMENDOUS! 找两个人打玛拉顿，一坦一奶` | 通过 |
| 结果框 Ctrl+V | 实际粘贴得到同一纯文本结果，不含请求标记 | 通过 |
| 准备“先杀奶” → Ctrl+C → Ctrl+V | 状态显示离线模拟、简短、9 字节；粘贴为“先杀奶” | 通过 |
| 直接从原句框复制未带标记的 LFM | 没有触发新处理，最近返回仍为先前简短结果 | 通过 |
| 点暂停，再复制完整带标记请求 | 状态保持暂停；稍后粘贴得到完整请求原文，未被改写覆盖 | 通过 |
| 应用设置恢复监听 | 状态为离线监听，未自动处理剪贴板中的旧请求 | 通过 |
| 恢复后重新复制同一句 LFM | 再次触发并完成，显示新的发挥结果 | 通过 |
| 准备新请求前已有旧预览 | 修复后自动清空旧预览；新结果可直接 Ctrl+V，不与旧内容拼接 | 修复并复测通过 |

本轮发现并修复：准备新请求时旧粘贴预览未清空，重复试用容易造成文本混合。另调整暂停时的准备提示，避免提示用户复制就能触发。

本记录不证明真实模型能正确分类、准确翻译或生成合格的讽刺，也不证明游戏兼容性。提示音调用有实现，但本次没有验证实际音频输出。最小化/其他应用、真实模型和正式游戏客户端继续按 ACCEPTANCE.md 单独验收。
