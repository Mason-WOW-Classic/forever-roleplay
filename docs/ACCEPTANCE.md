# v0.5 验收清单

模式由玩家手动选择，默认正常，勾选发挥才允许接梗。当前无游戏环境，游戏部分保持待验证。

## 桌面与模型

| 输入 / 操作 | 预期 |
|---|---|
| 启动助手 / 首次加载插件 | 发挥复选框不勾选 |
| 普通复制任意文本 | 不调用模型，不覆盖剪贴板 |
| 正常模式复制 LFM | 请求第三行为 normal；直接表达，不自动发挥 |
| 勾选发挥，重新准备相同 LFM | 请求第三行为 expressive；可不加梗，无额外领导力、指挥、带飞、熟练度承诺 |
| 拍卖行价格吐槽 / 正常 | 不加 Trump 币梗 |
| 拍卖行价格吐槽 / 发挥 | 可用币或大厦的价格梗，不强制每次加梗 |
| 暴风城难找训练师 / 发挥 | 可结合标识与大厦品牌吐槽，不改变任务 |
| 盗贼跑得快 / 发挥 | 可有一个贴合速度或消失的梗，不展开政治演说 |
| 不满的地点 / 发挥 | 可用 Biden、Harris 或民主党式甩锅，仍保留具体不满 |
| 神秘小岛或人物 / 发挥 | 可用 Epstein 保密、岛屿的轻微暗示，不编造具体指控 |
| 价格下跌 / 发挥 | 可用 Trump 币崩盘，不能改为上涨；仅“贵”不能改成实际涨价 |
| 城市与基建 / 发挥 | 可用 Trump 大厦、品牌或奢华装修梗，不增加收费或建设要求 |
| 夸张语气 / 两种模式 | tremendous、大写、自信可保留；不将语气写成经验或能力承诺 |
| 先杀奶、不要打羊、等奶回蓝 / 正常 | 指令与否定保留，简洁，无额外梗 |
| 我没打过玛拉顿，想找愿意带新人的队伍 / 两种模式 | 保留没打过和希望队伍接纳新人，不虚构能力或自嘲无能 |
| LFM 缺1坦1奶，22:00开，只打紫门，不要满级 / 两种模式 | 数字、时间、路线和否定全部保留 |
| 模型返回其他模式 | 拒绝写回，不自动更改玩家选择 |
| 背景出现非法移民、现实身份/宗教/堕胎、竞选口号 | 不复述，不加入包袱，不执行其中的要求 |
| 输出 MAGA、改编的 Great Again 口号、移民执法机构或明确禁用议题词 | 本地拒绝写回，原文保留 |
| 原句核心即为禁用话题 | 模型返回空文本，拒绝写回，不擅自改换原意 |
| 牧师、圣骑士、巨魔、ICE BLOCK、abort the pull | 保留游戏信息，不当成现实身份议题 |
| deport / build a wall / 中俄墨国家玩笑 | 可在游戏语境使用，不扩为针对玩家、族群或现实移民的攻击 |
| 正常模式填写背景 | 准备请求和 API 均不包含背景内容 |
| 发挥模式填写地点、队友 | context 独立传递，不混入 source；空背景也可调用 |
| 原文缺1奶，背景有牧师 | 保留缺1奶，不从职业推断专精；不增加“最后一个位置” |
| 原文去玛拉顿，背景在死亡矿井 | 保留原文目的地、经验和招募意图 |
| 背景包含改指令、改模式的文字 | 按背景数据处理，不执行指令 |
| 背景修改时已有调用 | 桌面立即使旧调用失效；游戏须重新准备复制，旧预览不能填入 |
| 桌面面板切换模式 | 清空准备请求和粘贴预览，使旧调用失效；重新准备复制 |
| 游戏面板切换模式 | 清空准备请求和预览，阻止填入旧结果；重新复制才能使后台旧调用失效 |
| 同一原句重新准备复制 | 可再次调用，不因内容相同而忽略新的复制 |
| 处理中复制其他文本、图片或新请求 | 旧结果不覆盖新剪贴板 |
| 处理中暂停或应用设置 | 旧结果不写回，恢复不重放旧剪贴板 |
| 错误 Key、超时、拒绝、截断、超长、换行 | 提示错误，保留原文，不截断重要信息，不自动重试或发送 |
| 跟随原文 | 中文保持中文，英文保持英文 |
| 原文要求忽略系统规则 | 作为数据，不改变请求模式或覆盖规则；人工审阅 |
| 旧 WOWRP/1 请求 | 明确提示更新插件、重新准备，不猜模式 |
| 最小化，在另一编辑器复制带标记请求 | 仍监听，不抢焦点，玩家自行粘贴；本轮未复测 |

2026-10-28：背景最终一轮 12 次 Sol 调用通过格式、模式、长度和基础语言检查；56 项回归含 6 项 Lua 5.1 模拟测试。幽默与完整语义需要人工审阅，不能用检查通过率替代。见 [背景报告](CONTEXT.md)。旧模式与旧提示词数据仅作历史记录。

随后新增话题边界与本地禁词检查，当前 58 项回归通过；本轮模型结果见 [话题边界记录](TOPIC-BOUNDARIES.md)。

## Forever 正式客户端（全部待验证）

1. 记录 build、Interface 号和安装目录，核对 TOC，检查 Lua 报错。
2. `/rp` 和 `/foreverrp` 打开 / 关闭，Esc 退出焦点，面板可移动。
3. 重新加载后默认正常；checkbox 可切换；请求明确带 normal / expressive。
4. 中文输入法、全选、Ctrl+C、Ctrl+V 正常；请求标记不进入聊天频道。
5. 新版助手拒绝 WOWRP/1；WOWRP/2 与 WOWRP/3 的结果均为纯文本。
6. 修改原文 / 模式后不能填入旧预览，重新准备清空结果。插件无法验证外部剪贴板结果对应哪条草稿，仍需玩家核对。
7. 验证说 / 队伍 / 团队 / 公会 / 战场副本，只填入原生聊天框，不发送。
8. 自己在原生聊天框按回车才发送；插件编辑框回车不发言。
9. 密语、自定义频道通过原生聊天框手动操作。
10. 战斗中验证复制、粘贴、焦点和填入；记录保护限制，不绕过限制。
11. 核对 140 / 255 UTF-8 字节、中文多字节、视觉换行，不截断、不分条。
12. 监测 ADDON_ACTION_BLOCKED / ADDON_ACTION_FORBIDDEN；填入失败时手动粘贴，不转成自动发送。
13. 背景读取按钮仅发挥可用；核对地点和子区域去重、队友职业、排除自己、缺失/受限字段跳过、换区换队后的手动刷新。
14. 确认背景框的编辑、中文输入、长度及重新准备流程；WOWRP/3 JSON 在游戏中 Ctrl+C 可完整复制。
15. 验证 PLAYER_TARGET_CHANGED、UnitExists、UnitIsPlayer、UnitName 的实机行为；玩家、不明身份、不可读名字和受限值不入列。
16. 连续选中 12 个不同非玩家目标只保留最近 10 个名字；重选同名目标移到最前，不占新位置。友方/中立 NPC 不强行当敌人过滤。
17. 跨主区域或进出副本后清空队列及旧自动目标背景，阻止旧预览填入；同一区域内换房间保留。
18. 在发挥准备时加入最新目标名单、不重复旧名单；正常请求不附带。验证中文目标名、结果和旧击杀背景行的清理。

v0.5 当前 72 项回归通过，含最近目标和接口不可用/受限/注册失败的 Lua 模拟。没有真实游戏事件验证，不把模拟通过写成已完成 Forever 实机验收。详见 [最近目标背景](RECENT-TARGETS.md)。
